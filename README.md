# EduNexus
# 🎓 EduNexus - LMS Portal

EduNexus is a modern Learning Management System (LMS) portal designed to provide an interactive and user-friendly platform for online learning. The platform allows users to explore courses, manage students, monitor analytics, and access educational resources through a clean and responsive interface.

---

## 🚀 Features

* 📚 Course Management System
* 👨‍🎓 Student & User Management
* 📊 Analytics Dashboard
* 🔍 Course Search Functionality
* 🌙 Modern Dark UI Design
* 📱 Fully Responsive Layout
* ⚙️ Admin Settings Panel
* ⭐ Course Ratings & Enrollment Display

---

## 🖥️ Screens Included

* Dashboard
* User Management
* Courses Page
* Analytics Section
* Settings Panel

---

## 🛠️ Technologies Used

### Frontend

### UI & Design

* Responsive Design
* Modern Dark Theme
* Interactive Components

## 🎯 Purpose of the Project

This project was developed to improve learning accessibility and provide a centralized platform where students can discover courses and administrators can efficiently manage educational content.
